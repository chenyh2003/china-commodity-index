# 中国消费 / 工业商品指数

## 1. 口径

### 1.1 层级

```
合约 → 品种 → 小指数 → 大指数
```

- 消费小指数：油脂、生猪、鸡蛋、白糖、棉花、苹果、红枣
- 工业小指数：金属、橡胶、原油、铁矿石+焦煤、黄金

### 1.2 品种价格

每个品种先计算“持仓加权平均价格”：

```
P(品种,t) = Σ [P(合约,t) × 持仓量(合约,t) × 乘数]
           / Σ [持仓量(合约,t) × 乘数]
```

- 只用月份合约；不把主力连续或加权连续计入月份合约加总，避免双计。
- 活跃条件：有结算价/收盘价、持仓量 > 0、未进入交割月。
- 数据缺失不超过 5 个交易日的，按前一有效值前向填充；超过 5 日按缺失处理。

### 1.3 小指数与大指数

品种价格指数：

```
I(品种,t) = P(品种,t) / P(品种,基期) × 1000
```

小指数：

```
w(品种,t-1) = G(品种,t-1) / G(小类,t-1)
I(小类,t) = Σ w(品种,t-1) × I(品种,t)
```

大指数：

```
w(小类,t-1) = G(小类,t-1) / G(指数,t-1)
I(指数,t) = Σ w(小类,t-1) × I(小类,t)
```

其中 `G = Σ 持仓量 × 价格 × 乘数`，即持仓市值。

- 权重用 t-1 日持仓市值，避免前视。
- 新上市品种在上市日以 1000 进入；当天权重为 0，下一交易日起参与。
- 某品种某日无有效合约 → 权重 0，同层重新归一，并记录覆盖率。
- 当前版本为每日按前一日市值调整权重；月度再平衡、权重上限、交易成本尚未加入。

## 2. 数据与历史

| 数据 | 来源 | 区间 | 用途 |
|---|---|---|---|
| 商品期货主力连续 | Warehouse `futures_main_sina` | 2005-01 ~ 2026-10 | 2005-2019 长历史代理 |
| 逐合约日线 | 新浪 `futures_zh_daily_sina` | 2020-01 ~ 2026-10 | 2020 后正式口径 |
| 沪深300 | 新浪 `stock_zh_index_daily(sh000300)` | 2005-01 ~ 2026-10 | 比值图下方对照 |
| 合约乘数/交割月 | 交易所合约文本 | 当前 | 市值与价格计算 |
| 交易日历 | 行情并集 | 2005-2026 | 对齐 |

关键历史节点：

- **2020-01-03**：逐合约正式口径可完整覆盖当月活跃合约，主指数起点。
- **2021-02-01**：消费指数全部 10 个品种齐全。
- **2025-11-27**：铂、钯（GFEX）上市，工业全成分指数起点。
- **2005-01-05**：主力连续代理指数起点。

限制：

- Warehouse 的 `futures_contracts` 只有 CU 和 C 两个品种，逐合约数据来自新浪。
- 新浪逐合约历史约保留 2020 年以后到期的合约，2019 年到期合约已不可得，因此正式口径从 2020 年开始。
- DCE 官方历史接口有反爬，未使用；DCE 品种的逐合约数据同样来自新浪。
- 花生油没有期货合约，用花生 PK 替代。
- 橡胶暂只用 RU，未加入 NR/BR。
- 长历史代理使用主力连续，换月跳空无法完全消除；已剔除持仓市值异常低的交易日，并检查日收益超过 10% 的异常点。

## 6. 网站

入口：`site/index.html`，也可以双击根目录的 `打开网站.bat`。

功能：

- 顶部两个大指数卡片：消费指数、工业指数（按持仓市值加权）。
- 比值曲线：工业/消费、消费/工业，支持 2020 与 2005 长历史口径；下方附沪深300对照。
- 大指数、小指数、比值的勾选开关，可单独打开/关闭任意曲线。
- 小指数支持“2020 逐合约 / 2005 长历史”切换。
- 快捷筛选：全部、仅消费、仅工业、全不选。
- 小指数支持对数轴、时间轴缩放。
- 所有数据和 Plotly 库均在本地，断网也能打开。
